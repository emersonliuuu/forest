# Formosa Forest

**A walkable, real-time subtropical mountain forest modelled on Taiwan, in one self-contained HTML file.**

The island has Taiwan's outline and broad relief. Walk from the coast to the 3,950 m summit and the forest changes around you: banyans and bamboo, laurel–oak forest with tree ferns, foggy cypress cloud forest, hemlock and spruce over a cane carpet, Taiwan fir, and finally alpine juniper and rhododendron above a sea of clouds.

Everything is generated by code at load time: no image, model or sound files. Rendering is raw WebGPU (no engine).

## Try it

1. Download [`index.html`](index.html) and open it in **Chrome or Edge** on a desktop computer (WebGPU is required).
2. Wait a few seconds while the island is generated, then click to start.

| Key | Action |
|---|---|
| W A S D | walk |
| Mouse | look (click to capture the pointer) |
| Shift | sprint |
| Space | jump |

The altitude and the current forest zone are shown bottom-left. You spawn at a random place on land each time.

### URL parameters

| Parameter | Effect |
|---|---|
| `?seed=7` | reproducible spawn position |
| `?goto=sacred` / `bridge` / `rail` / `summit` | start next to a set piece (giant cypress, suspension bridge, logging railway, summit marker) |
| `?shot=0` … `5` | start at the fixed test pose of forest zone 0–5 |
| `?bench=1&seed=3` | run the scripted 60 s climb and print GPU / frame-time statistics |
| `?w=2560&h=1440` | force the render resolution |
| `?msaa=1` | disable 4× MSAA |

## What is in the world

- **Island**: coastline polygon (41 points) and six ridge splines give the outline, the central spine, the steep east flank, the western foothills and the eastern coastal range. Noise adds valleys, streams, terraces and crags. Horizontal scale is compressed about 8× (the island is 24 × 45 km); altitudes are real.
- **Six forest zones** blended by altitude with a noise offset, 25 plant and animal meshes, GPU-baked impostors for distant trees.
- **Atmosphere**: sun flecks and light shafts through the canopy, wind sway, lowland haze, cloud-belt fog, sea of clouds seen from above.
- **Water and rock**: streams with pools and waterfalls in the valleys, mossy boulders, cliffs and scree higher up, ocean to the horizon.
- **Life**: butterflies, fireflies, bird flocks, macaques, pheasants, deer herds, falling leaves, pollen.
- **Set pieces**: a sacred giant cypress, a suspension footbridge over a gorge, an abandoned logging railway, a summit marker.

## How it works

- `source/src/world.js`: island generator and the height function. The same function is mirrored in WGSL, so CPU collision, GPU terrain and GPU plant placement agree.
- `source/src/shaders.js`: all WGSL. A compute pass scatters, culls and LODs every plant and animal each frame straight into indirect draw lists, so the CPU does no per-frame instance work.
- `source/src/mesh.js`, `atlas.js`: procedural meshes and the leaf texture atlas.
- `source/src/main.js`: device setup, frame loop, controls, bench and capture hooks.
- Frame: placement compute → 2 shadow cascades → 4× MSAA HDR scene (alpha-to-coverage foliage) → half-resolution volumetrics (shafts, mist, cloud sea) → composite and tone map.

The frame loop uses preallocated typed arrays and descriptors. The only per-frame objects are the WebGPU handles the API itself returns (command encoder, passes, swap-chain view).

## Build

```bash
cd source && npm install && npm run build
```

This writes `../index.html` and prints its size.
